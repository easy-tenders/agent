# Инструмент — Satu

Вторая площадка для снятия рыночной цены. Оптовее Kaspi: в кондиционерах
15 000+ позиций. Проверено прогоном 2026-07-25.

**Что умеет:** каталог с сортировкой по цене — `&sort=price`. Работает стабильнее
Kaspi, снимается скриптом.

## Лимиты и грабли

- **Не всегда дешевле:** по одним моделям минимум даёт Satu, по другим — Kaspi.
  Брать минимум из обеих.
- **Цена всё равно розничная** — потолок, не закупка.
- **Ozon.kz для казахстанских тендеров не подходит** — цены выше, чем платит
  заказчик. Проверено, больше не берём.

## Правила

- Годится **любая площадка**, включая китайские — слово владельца 25.07: «Kaspi не
  обязателен, Satu тоже подходит».
- Ничего не заказываем.
- **Доступ:** вход не нужен.
