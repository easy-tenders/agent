# Инструмент — Kaspi

Маркетплейс, одна из двух площадок, по которым снимается рыночная цена товара под
лот. Проверено прогоном 2026-07-25.

**Что умеет:** каталог товаров с ценами; годится, чтобы получить верхнюю границу
цены по модели.

**Как пользоваться:** только **через браузер** — каталог рисуется скриптами, API
отдаёт 403. Карточки товара: `.item-card`, имя `.item-card__name`, цена
`.item-card__prices-price`.

## Лимиты и грабли

- **Цены привязаны к зоне доставки** — в адресе появляется `Magnum_ZONE5`. Для лота
  в другом городе считать по **его** зоне, иначе расчёт не про тот регион.
- **Продавцы конкретного товара через скрипт не снимаются** — подгружаются
  асинхронно.
- **Не всегда дешевле:** по «семёрке» дешевле Satu, по «девятке» — Kaspi. Брать
  минимум из обеих площадок.
- **Цена розничная** — это потолок. Реальная закупочная ниже, значит настоящая
  маржа выше расчётной.

## Правила

- **Капчу не обходим:** стоит защита — страницу открывает человек, агент читает.
- Ничего не заказываем и не отправляем.
- **Доступ:** вход не нужен, каталог публичный.
