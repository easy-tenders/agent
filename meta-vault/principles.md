# Принципы — правила письма (база-баз)

**База** конвенций для всего неймспейса. Vault доменов фиксируют только
свои **дельты**. Структура и точки входа — [[vault-template]]; этот файл —
правила письма на уровне объектов. Термины — [[glossary]].

**Ядро:** один файл = один объект · имя файла = его роль и поисковый крючок ·
связи через `[[…]]` · плоская структура · frontmatter · без секретов
(только указатели) · один язык базы.

## Шов: знание или запись

Перед каждой записью — один вопрос:

> *«это как мы делаем / что мы знаем — или что мы сделали / что у нас есть?»*

Знание → vault: метод, форма, принцип, описание папки записей, решение, урок.
Запись → папка рядом с vault: строка реестра, состояние, журнал, план, карточка
человека или клиента. Vault, в котором лежат данные, разрастается и теряет
карту — это первая причина, по которой базы «едут».

## Правила

- **Имя файла = его роль.** `CLAUDE.md` дверь · `HOME.md` карта · `<имя>.md`
  описание зоны или папки записей `<имя>/` (файл **рядом** с папкой, не
  внутри) · `registry.md` таблица строк внутри папки записей · `form.md` форма
  файлов подполки · `card.md` запись одного объекта. **`README.md` — только в
  коде, который читают снаружи** (корень репозитория на GitHub).
- **Ссылки.** На уникальное имя — именем (`[[glossary]]`); на имя, которое
  повторяется по доменам (`HOME`, `status`, `principles`, `operations`, …), —
  **путём** от файла (`[[../../meta-vault/principles|principles]]`). На
  папку ссылок нет — папки пишутся кодом. Пайп в ссылке внутри таблицы
  экранируется: `[[id\|Имя]]`. Проверка — `bin/check`.
- **Зона и папка рождаются с первым объектом**, не на вырост — и в тот же
  момент получают строку в карте и двери. Папка без строки в карте не
  существует.
- **Ничего не удаляется.** Мёртвое — в `../archive/` + строка в
  `../archive/INDEX.md`. `_archive/` внутри vault — терминальная зона; из
  карт ссылок туда нет, из решений (провенанс) — можно.
- **Дословное — дословно.** Слова владельца в решениях и карточках —
  цитатой с датой, не пересказом. Первоисточник (дневник, авторские тексты) в
  vault не копируется: он живёт по своему пути, здесь — заметки *о* нём.
- **Sensitivity.** `sensitivity: normal | private`; `private` никогда не
  уходит в публичный remote.
- **Scope.** `scope: personal | work | all` — кто читает/использует.
- **Axis** — только там, где снимает неоднозначность: `axis: vault | agentic
  | engine | cross` ([[glossary]]).
- **Размер.** Мягкий потолок ~120 строк — для односмысловых справочных
  файлов; решения и разборы длиннее, их держит структура, а не счётчик.
- **Изменённая форма датируется; старые файлы массово не переписываются.**
  Форма получает строку «с YYYY-MM-DD пишем так» в журнале
  ([[vault-template]] §Журнал формы); старое переписывается только по слову
  владельца.
