# Проверить базу

**Когда:** «проверь базу», «всё ли на месте», «ничего не сломалось?» — и
**обязательно** перед передачей, после любой правки раскладки и после
приёма новой версии шаблона.

**Зачем прогоном, а не глазами.** Битую ссылку не видно: файл открывается,
текст читается, а связь мёртвая. Число без прогона не пишется.

## Шаги

1. `python3 bin/check` из любого места неймспейса. Считает: битые связи ·
   неуникальные имена без пути · ссылки на папки · неэкранированный пайп в
   таблицах · похожее на секрет в индексе git · секреты под git · оставшиеся
   `<настрой>`. Код в fenced-блоках и в `обратных кавычках` не считается —
   формы показывают образцы.
2. Числа с датой — в `meta-vault/structure.md` §Здоровье. Ноль без даты — не
   запись.
3. Нашлось битое → чинить **отдельно**: прогон только считает. Ссылку на
   неуникальное имя — путём; коллизию имён — переименованием файла данных,
   не описания.

**Крайние случаи:**

- Ссылка на ещё не заведённое, намеренно → остаётся, но перечисляется в
  `structure.md` поимённо; «битых 0» тогда писать нельзя.
- Базы нет в git → секреты в индексе не проверены, `bin/check` это скажет;
  гарантии «не уехало» нет.
