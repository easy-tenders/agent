# Разобрать inbox

- **вызов:** фраза — «разбери inbox», «что я накидал»
- **исполнитель:** агент
- **статус:** possible

## Когда

«разбери inbox» · «что там накидано» · регулярная сессия разбора.

## Шаги

1. Прочитать `../../planning/inbox.md` и `../../planning/inbox/` (если есть).
2. Каждый пункт — в один из домов: задача → `<домен>/planning/backlog.md`
   домена-исполнителя + строка в `../../planning/backlog.md`; идея →
   `ideas/`; внешний материал → домен, которому он нужен; мусор →
   `../../archive/` строкой в `INDEX.md`.
3. ⏸ владелец — спорное (непонятно, чей пункт, или похоже на решение)
   спрашивается текстом, по одному.
4. Разобранное вычеркнуть из `inbox.md`; в чат — одной строкой, что куда ушло.
