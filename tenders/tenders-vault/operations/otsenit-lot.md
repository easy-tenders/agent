# Операция — оценить лот

**Когда:** «стоит ли участвовать», «посчитай этот лот», «что по <номер лота>»,
«сколько тут заработаем».

Порядок жёсткий: сначала допуск, потом требования, только потом деньги. Считать маржу
по лоту, в который нельзя зайти или под который нет товара, — пустая работа.

**Шаги:**

1. **Проверь способ закупки.** Если «из одного источника по несостоявшимся закупкам» —
   поставщик уже приглашён, участвовать нельзя. Скажи это и остановись.
2. **Сними карточку лота** — `engine/scripts/ows.py lot <id>` (id — из выдачи
   «найти лоты»): заказчик, характеристика, цена за единицу, количество, сроки
   приёма и поставки, способ закупки. Без токена — адрес и поля по памятке
   [[goszakup]]; код ТРУ — только там, API его в карточке не отдаёт.
3. **Открой документацию** — `ows.py docs <id>` кладёт техническую спецификацию
   и проект договора в папку, `extract_docs.py <папка>` даёт их текст. Без токена —
   по памятке [[goszakup]]: документы грузятся отдельным запросом по номерам групп.
   **Без этого шага дальше не идти:** в карточке одна строка, в спецификации два
   десятка требований.
4. **Выпиши требования из спецификации** — все, включая год выпуска, гарантию,
   сопутствующие услуги (доставка, монтаж, пусконаладка, обучение) и ГОСТы.
5. **Найди обязательные платежи:** обеспечение заявки (в документации закупки) и
   обеспечение исполнения договора (в проекте договора). Это замороженные деньги.
6. **Подбери товар по требованиям, а не по цене.** Сначала отсей всё, что не проходит
   по параметрам, потом среди оставшихся ищи минимальную цену. Цены снимаются с
   площадок — памятки [[kaspi]] и [[satu]], брать минимум из обеих. Если ни одна
   модель не проходит — так и скажи, не подставляй похожую.
7. **Посчитай деньги** по операции [[schitat-marzhu]].
8. **Дай вердикт**: участвовать, рискованно или нет — с указанием, что именно решает.
9. **Положи разбор в базу** — [[zavesti-kartochku-lota]]. Иначе работа исчезает.
10. **⏸ operator:** покажи вердикт владельцу. Решение подавать и сама подача —
    её, не твоё: ЭЦП, отправка и подписание к агенту не относятся.

**Крайние случаи:**
- В характеристике нет параметров (только «настенный») → лот помечается как требующий
  уточнения у владельца, маржа не считается.
- Характеристики противоречат друг другу (в кратком «оконный», в дополнительном
  «настенный») → поднять вопросом, не выбирать самому.
- Цена заказчика ниже рыночного минимума → лот отбрасывается сразу, это объясняет,
  почему закупка не состоялась.

**Важно:** пустое поле в карточке не значит «ноль» или «не требуется». Если поле
пустое — значит не смотрели.
