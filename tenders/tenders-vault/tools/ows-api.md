# Инструмент — унифицированные сервисы портала (API по токену)

`ows.goszakup.gov.kz` — программный доступ к данным портала госзакупок: те же
лоты, объявления, договоры, годовые планы и участники, что на сайте, но в JSON,
за секунды и без разбора HTML. Исполнитель — `engine/scripts/ows.py`
(`inventory/executors.md`). Памятка про сайт и HTML — [[goszakup]]: когда
токена нет, работает она.

## Токен

- Выдаётся в кабинете портала: **Профиль участника → Выпуск токена (для
  разработчиков)**, роль «Администратор организации». Срок — год, перевыпуск
  там же. Первичный — по письму в АО «Центр электронных финансов».
- Хранится в `secrets/goszakup-token` (вне git) или в переменной среды
  `GOSZAKUP_TOKEN`. Карта — `meta-vault/secrets-map.md`. В файлы базы
  значение не попадает.
- **Привязан к IP-адресу**, указанному при выпуске (практика, не документ):
  без токена портал отвечает 401, с токеном с чужого адреса — 403 «Вам не
  разрешено производить данное действие». Проверка одной командой:
  `python3 engine/scripts/ows.py check`. Снято 23.10.2026: токен принят,
  доступ с машины Макси — 403; тест — с машины, чей адрес указан в кабинете.

## Адреса

| Что | Адрес | Примечание |
|---|---|---|
| GraphQL (основной) | `POST https://ows.goszakup.gov.kz/v3/graphql` | фильтры по тексту, статусу, сумме, КАТО, дате; схема — `https://ows.goszakup.gov.kz/help/v3/schema/` |
| REST v2 | `GET https://ows.goszakup.gov.kz/v2/<реестр>` | без фильтров по тексту; нужен для справочников `/v2/refs/<имя>` |
| Документация | `https://old.goszakup.gov.kz/ru/developer/ows_v2` · `/ows_v3` | V1 (`/lots` без версии) выключен |

Заголовки: `Authorization: Bearer <токен>` · `Content-Type: application/json`.
Страница GraphQL — до 200 записей; следующая страница — аргумент `after` =
`extensions.pageInfo.lastId` предыдущего ответа; `totalCount` — всего.

## Объекты и фильтры, которыми пользуемся

| Запрос | Фильтр | Поля, которые берём |
|---|---|---|
| `Lots` | `nameDescriptionRu` (название + описание, морфология), `refLotStatusId`, `amount`, `plnPointKatoList` (начало кода КАТО), `customerBin`, `trdBuyId`, `lastUpdateDate` | номер, статус, кол-во, сумма, заказчик, `TrdBuy{endDate, способ, biinSupplier}`, `Files{filePath}` — документы лота |
| `TrdBuy` | `nameRu`, `refBuyStatusId`, `publishDate`, `strKato`, `orgBin` | объявление: сроки приёма, способ, организатор, поставщик из одного источника |
| `Contract` | `trdBuyId`, `customerBin`, `supplierBiin`, `finYear`, `signDate` | кто и за сколько заключил: сумма, поставщик, заказчик |
| `Plans` | `nameDescriptionRu`, `plnPointYear`, `subjectBiin`, `refTradeMethodsId` | годовые планы: что заказчик собирается купить, когда, за сколько — **до объявления** |
| `Subjects` | `bin`, `iin`, `nameOrFullNameRu`, `katoList` | участник: имя, регион, признаки |
| `TrdApp` | `buyId` | заявки поставщиков на закупку: цены участников |

**Синтаксис текстового поиска:** `слово` — точное совпадение; `?слово` — часть
слова без морфологии; `*слово` — с морфологией. `ows.py` сам ставит `*`, если
владелец не написал знак. Даты — списком: `["2026-01-01","2026-12-31"]` = С … ПО.

**Статусы лота:** открытые — 210, 220, 240 (как в поиске по HTML); полный
список — `ows.py refs ref_lots_status`. Способы закупки — `refs ref_trade_methods`;
лоты «из одного источника по несостоявшимся» определяем по имени способа и по
`TrdBuy.biinSupplier`. КАТО: Карагандинская область — коды с `35`, Астана —
`71`, Алматы — `75`; список — `refs ref_kato --find Караганд`.

## Команды

```
python3 engine/scripts/ows.py check
python3 engine/scripts/ows.py lots "кондиционер" --kato 35 --min 500000
python3 engine/scripts/ows.py lot <id>
python3 engine/scripts/ows.py won "кондиционер" --year 2025
python3 engine/scripts/ows.py contracts --customer <БИН>
python3 engine/scripts/ows.py plans "кондиционер" --year 2026
python3 engine/scripts/ows.py subject <БИН>
python3 engine/scripts/ows.py refs ref_trade_methods
python3 engine/scripts/ows.py selftest        # разбор без сети
```

Выдача — таблицы в консоль (доступные и «из одного источника» раздельно,
истёкшие отсеяны) и JSON во временную папку; в базу попадает только то, что
записано операцией.

## Грабли

- 403 на всём, включая справочники, — адрес, не права. Не чинить кодом.
- Лимит страницы 200; выдача по общему слову («бумага») — тысячи лотов: сужать
  КАТО, суммой, статусом.
- `Files.filePath` у лота — путь к документу; скачивание самого файла идёт с
  сайта портала как в [[goszakup]], по токену файлы не отдаются (не проверено,
  снять при первом живом прогоне).
- Вложенные объекты (`Supplier`, `Customer`, `PlansKato`, `Address`) взяты из
  схемы; если портал на них ругнётся, скрипт повторяет запрос без них.
- **Ни одна команда, кроме `selftest`, не прогонялась вживую** — первый
  доступ покажет расхождения со схемой; записать их сюда.
