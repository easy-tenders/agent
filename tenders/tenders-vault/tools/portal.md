# Портал госзакупок РК — карта (браузер)

`v3bl.goszakup.gov.kz` — веб-портал АИИС ЭГЗ (Минфин РК). Кабинет залогинен в
Chrome под кабинетом владельца (сторона поставщика). Использовать
браузер для действий, которых нет в MCP (профиль, избранное, подача); для
данных — предпочитать [[tenders/tenders-vault/tools/mcp|MCP]].

> Приватное (логин, IP, личные данные кабинета) сюда не выписывать — только
> факт «залогинено», без значений.

## Навигация (верхнее меню)

- **Закупки**
  - Поиск лотов — `/ru/search/lots` (рабочая лошадка ресёрча).
  - Поиск объявлений — тендеры целиком (внутри — лоты).
- **Реестры**
  - Реестр жалоб · Реестр недобросовестных участников ГЗ · Реестр опытов работы ·
    Реестр недобросовестных участников закупок · Реестр участников ГЗ ·
    **Планы ГЗ** · **Реестр договоров** · Реестр квалифицированных поставщиков.
- **Кабинет:** Рабочий кабинет · Личные данные · Профиль участника ·
  Внешние сервисы · Избранное.

## Поиск лотов — фильтры

Наименование/описание лота · № лота · № объявления · **код ЕНС ТРУ** · способ
закупки · статус · место поставки · заказчик · сумма закупки (с/по) · предмет
закупки · срок закупки (план). Есть «Статистика» и «Расширенный поиск».

## Заметки

- Прямой переход на `/ru/search/lots` работает; из меню «Закупки → Поиск лотов».
- Язык интерфейса переключается `/ru/` ↔ `/kz/` в URL.
