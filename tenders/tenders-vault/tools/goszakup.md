# Инструмент — портал госзакупок

`goszakup.gov.kz` — публичная часть портала государственных закупок Казахстана.
Основной источник данных базы. Всё проверено прогоном 2026-07-25 на нише
«кондиционеры»: это описание работающего, а не план.

**Что умеет:** поиск лотов и объявлений, карточка лота, документация закупки
(техническая спецификация, проект договора), протоколы итогов, реестр договоров.

**ЭЦП не нужен.** Вся работа до подачи заявки делается на публичной части обычными
HTTP-запросами — портал отдаёт готовый HTML, браузер не требуется. Ключ понадобится
только для самой подачи, а это действие владельца.

## Адреса

Искать надо **по названию лота**, а не объявления: объявление называется
«Приобретение машин и оборудования», а товар сидит внутри лота.

| Что | Адрес |
|---|---|
| Поиск лотов | `/ru/search/lots?filter[name]=…` |
| Поиск объявлений | `/ru/search/announce?filter[name]=…` |
| Карточка лота | `/ru/subpriceoffer/index/<объявление>/<лот>` |
| Объявление | `/ru/announce/index/<id>` |
| Вкладки объявления | `?tab=lots` · `?tab=documents` · `?tab=protocols` · `?tab=winners` |
| Реестр договоров | `/ru/registry/contract?filter[buy_name]=…` · `filter[enstru]=<код ТРУ>` |

**Документы лота грузятся отдельным запросом** — это неочевидно и было пропущено
в первом прогоне:

```
/ru/announce/actionAjaxModalShowFiles/<объявление>/<группа>
```

(проверено 23.10; без сегмента `announce/` портал отвечает 404). С токеном
проще: `engine/scripts/ows.py docs <id лота>` — памятка [[tenders/tenders-vault/tools/ows-api|ows-api]].

Номера групп берутся со страницы `?tab=documents` из вызовов
`actionModalShowFiles(<объявление>,<группа>)`. Ответ — список файлов со ссылками
на `v3bl.goszakup.gov.kz/files/download_file/…`.

## Коды фильтров

Снимаются со страницы поиска (`<select name="filter[…]">`), меняются редко.

| Фильтр | Значения |
|---|---|
| `filter[status][]` | `220` — приём заявок · `240` — приём ценовых предложений · `210` — опубликован (вместе 210+220+240 — **текущие**) · `360` — закупка состоялась (**история**) |
| `filter[method][]` | `3` — запрос ценовых предложений · `2` — открытый конкурс · `78` — аукцион · `6` — из одного источника по несостоявшимся |
| `filter[trade_type]` | `g` товар · `s` услуга · `r` работа |

Всего 24 способа закупки и 26 статусов — полный список берётся из формы.

**Адрес с осени 2026 (проверено 22.10).** `goszakup.gov.kz` переадресует поиск,
лоты и объявления на **`old.goszakup.gov.kz`** — там всё работает, как раньше;
корень `goszakup.gov.kz` ведёт на новую «Единую платформу закупок»
`zakup.gov.kz`, поиска лотов там нет. `procurement.gov.kz` — зеркало старого
портала. Движок ходит на `old.` с запасом на зеркало (адрес — одна строка в
`engine/common.py`). Файлы протоколов — по-прежнему `v3bl.goszakup.gov.kz`.
В статусе 220 встречаются лоты 2018 года с давно истёкшим сроком — движок
отсеивает их по дате окончания приёма. Разбор — proverka-poiska-2026-10-21.
Если переедет снова: API портала по токену (`ows.goszakup.gov.kz`) уже живой —
памятка [[tenders/tenders-vault/tools/ows-api|ows-api]], токен в `secrets/`.

## Лимиты и грабли

- **Выдача обрезается на 10 000 записях**, по 50 на страницу. Для глубокой истории —
  нарезка по датам.
- **Протокол выписан на объявление, а не на лот.** Внутри может быть несколько лотов,
  у каждого своя плановая сумма и свои участники. Разбирать по блокам `Лот №`.
- **Структура таблиц в протоколах разная:** где-то есть колонка «цена за единицу»,
  где-то только «сумма по статье 13» и «общая сумма поставщика». Сравнивать надо
  **общую сумму поставщика с плановой суммой** — иначе получается мусор.
- **Колонки в PDF разделены двумя и более пробелами.** Резать строку по одному
  пробелу нельзя: числа склеиваются («170000 680000» → 1700000680000). Реальная
  ошибка прогона.
- **Протоколы двуязычные**: казахский блок («теңге»), русский дальше в том же
  файле — ищется по строке «Протокол об итогах»; движок принимает оба написания.
- **Поиск договоров по коду ТРУ (`filter[enstru]`) дал ноль** — либо там другой
  справочник, либо код берётся иначе. Не разобрано.
- **У закупок «из одного источника» протоколы устроены иначе** — обычный разбор
  ценовых предложений на них не работает. Вкладка `?tab=winners` в проверенном
  объявлении оказалась пустой.

## Правила

- **Капчу не обходим.** Стоит защита — сценарий переделывается так, что страницу
  открывает человек, а агент читает.
- **Ничего не подаём и не отправляем.** Агент только читает; подача — `⏸ operator`.
- Между запросами — пауза; не долбить.
- **Доступ:** не требуется, часть публичная. ЭЦП — у владельца, в базе не хранится.
